2025: My Data Journey

After graduation, I struggled to find a job. I knew I wanted to work in data, but everywhere I looked, I kept hearing about Python, SQL, Power BI, Tableau, and so many other skills.

I tried to learn everything at once because I needed a job.

For a while, I focused more on learning tools than actually building projects.

Now, I'm learning and building in public, starting with Excel → SQL → Python.

My goal is simple: build real projects, become a strong Data Analyst, and grow from there.
